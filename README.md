## 윈도우 전용

- `Win+Alt+Space` 로 불러서 한 줄 명령어
  - Powertoys랑 같이 쓸 수 없음!
- 마도카랑 목표를 쪼개고, 수다 떨고, 할 일과 메모를 적고, 화면을 잘라 검색하고, 폰이랑 파일을 주고받는다.
- 빈 입력칸에서 화살표 하나로 화면을 옮긴다: `←` 목표 쪼개기 · `→` 수다 · `↓` 메모장

### 목표 쪼개기

큰 목표를 위에서 아래로 뻗는 마인드맵으로 쪼개 나간다 (`backend` → `arch` + `sec`… → `sec` → `auth`, `crypto`…).
마도카한테는 대화 기록 대신 지금 트리와 고른 칸만 보여준다. 수다 화면과는 따로 논다 (호감도·기억도 안 건드린다).

| 기능                           | 부르는 법                                                                   |
| ------------------------------ | --------------------------------------------------------------------------- |
| 들어가기 / 나가기              | 빈 입력칸에서 `←` / `Esc` 또는 빈 입력칸에서 `→` (친 게 있으면 `Alt+→`)     |
| 마도카랑 쪼개기                | 입력칸에 말하기 (`sec 더 쪼개줘`, `jwt 할 일에 넣어줘`)                     |
| 고른 칸 바로 쪼개기            | 입력칸 `↑↓` 로 칸 고르고 빈 입력칸에서 `Enter`                              |
| 맵에서 옮겨 다니기             | 맵에서 `↑` 부모 · `↓` 첫 자식 · `←→` 형제                                   |
| 끝냄 · 할 일에 · 접기 · 지우기 | 맵에서 `Space` · `T` · `F` · `Del` (오른쪽 클릭 메뉴도 같다)                |
| 칸 메모                        | 고른 칸을 한 번 더 누르기 — 쪼갤 때 마도카가 한 말이 적혀 있고 고칠 수 있다 |
| 칸 이름으로 검색               | 고른 칸을 두 번 누르기 (부모 + 칸 이름으로 브라우저 검색)                   |
| 새 목표 / 목표 갈아타기        | 위쪽 `＋` / 목록에서 고르기, 입력칸에서 `Alt+↑↓`                            |

> 할 일에 넣으면 목표 이름이 카테고리가 된다. 목표는 지우지 않아도 여러 개를 두고 갈아탈 수 있다.
> 칸 메모는 따로 저장 단추가 없다 — 글 칸을 한 번 눌러야 고쳐지고, `Esc`/`Ctrl+Enter` 로 닫을 때 저장된다. 비어 있으면 마도카한테 써 달라고 할 수 있다.
> 마도카랑 주고받은 말풍선은 오른쪽 클릭으로 복사 · 지우기 (지워도 마도카가 아는 트리는 그대로).

## 마도카랑 수다

카카오톡처럼 내 말은 오른쪽, 마도카 말은 왼쪽 말풍선으로 뜬다.

- **링크 읽기** — 방금 보낸 말에 `http(s)://` 주소가 있으면 마도카가 그 페이지를 직접 열어 읽고 답한다 (Gemini `url_context`). 말풍선 속 주소는 밑줄이 쳐지고 누르면 브라우저로 열린다.
- **먼저 말 걸기** — 한동안 뜸하면 마도카가 먼저 말을 건다. 하루(달력 날짜)에 한 번까지다.
  - 내 말에 답을 못 한 채 끊겼으면, 하던 얘기는 내려놓고 마도카가 제 얘기를 먼저 꺼낸다.
  - 마도카 말을 읽고 답을 안 했으면 혼나고, 안 읽었으면 가볍게 한마디 더 얹는다.
- **할 일 얘기** — 말에 "할 일" 이 나오거나 오늘 할 일 하나를 콕 집어 말하면 ("영어 숙제 하기 싫다") 마도카가 오늘 할 일 목록을 보고 답한다.
- **호감도** — 0 에서 시작해서 답마다 오르내린다. 머리말에 이모지와 함께 숫자가 뜨고, 두 번 누르면 왜 바뀌었는지 마도카 속마음 한마디와 함께 모아 보여준다. `채팅 삭제` 를 해도 호감도 값과 추려둔 기억은 그대로 남고, 오르내린 사유만 그 대화에 묶여 같이 비워진다.
- **비밀 쪽지** — 마도카가 먼저 말을 걸 때(뜸할 때, 할 일 재촉·칭찬, `\\`) 접힌 쪽지(💌)로 보낸다. 눌러야 펼쳐지고, 한 번 연 쪽지는 "열어봄" 으로 바뀌지만 계속 다시 열 수 있다. 쪽지를 쓸지, 한 번/두 번 눌러 열지는 `설정` 에서 고른다.
- **지난 대화** — `채팅 삭제` 에서 "보관하고 지우기" 를 고르면 대화가 그 상대 폴더의 `chats_old/` 에 남는다. 그 대화에서 호감도가 오르내린 사유(와 지울 때 값)도 같이 보관된다.
- **윈도우 알림** — 위젯을 안 보고 있을 때(숨겼거나 딴 창을 쓰는 중) 마도카가 말을 하면 윈도우 알림으로도 뜬다. 누르면 수다 화면으로 들어온다.

## 오늘 할 일

[투두메이트](https://www.todomate.net/) 앱 모양을 따랐지만, 서버 없이 **이 컴퓨터에만** 적어둔다 (`json/todo/`).
입력칸 밑 왼쪽에 오늘 할 일이 뜨고, 검색 결과가 뜨면 그 자리를 내준다.

- 카테고리마다 이름표를 달고 그 밑에 할 일을 늘어놓는다. 지운 카테고리에 남은 할 일은 맨 끝 `기타` 로 간다.
- 네잎 체크칸을 누르면 체크/해제, 줄에 마우스를 올리면 뜨는 `✕` 로 지운다. 이름표 옆 `＋` 로 그 카테고리에 할 일을 넣는다 (`Enter` 넣기, `Esc` 닫기).
- 이름표를 오른쪽 클릭하면 이름 바꾸기 · 지우기, 할 일을 오른쪽 클릭하면 이름 바꾸기 · **내일로 미루기**. 미루면 마도카가 비밀 쪽지로 혼낸다.
- 하루는 자정이 아니라 **아침 6시**에 바뀐다. 날이 바뀌면 전날 못 끝낸 일이 오늘로 넘어와 진한 핑크로 뜨고, 그날 처음 들를 때 마도카가 재촉한다.
- 절반 끝냈을 때(두 개 이상일 때), 다 끝냈을 때, 다 끝낸 뒤 더 적은 걸 끝냈을 때 마도카가 칭찬한다.
- `todo` 창은 위에 한 주 줄, 밑에 고른 날 할 일. 날짜 칸이 네잎 모양으로 남은 개수(다 끝냈으면 체크, 빈 날은 회색)를 보여준다. `‹ ›` 한 주씩, `← →` 하루씩, `Esc` 닫기.
- 지난 날 기록은 지우지 않고 쌓아둔다. 밀려서 나중에 끝낸 건 그 전 날 기록에서 취소선으로 보인다.
- 새로 읽는 건 위젯에 포커스가 들어올 때뿐이다.
- 카테고리 색은 `설정` 의 "할 일 색" 에서 묶음을 고르거나 칸마다 직접 고른다.

## 설정

`settings` / `설정` 창에서 고친다. 저장하면 껐다 켜지 않아도 바로 먹는다 (`settings.json`).
탭이 셋이고, 폴더 말고는 칸마다 "기본으로" 가 있다.

**🎨 위젯 UI**

| 칸           | 하는 것                                                             |
| ------------ | ------------------------------------------------------------------- |
| 위젯 색 테마 | 위젯 전체 색. 기본은 파트너 색을 따른다                             |
| 위젯 투명도  | 바탕만 더/덜 비치게 (글씨와 그림은 그대로). 끄는 동안 바로 비춰본다 |
| 할 일 색     | 카테고리에 돌려 쓰는 색 — 기본 / 테마 따라 / 칸마다 직접 고르기     |

**🌸 캐릭터** — Gemini 키가 없으면 잠겨 있다 (`keys` 로 먼저 넣는다)

| 칸                | 하는 것                                                                                               |
| ----------------- | ----------------------------------------------------------------------------------------------------- |
| 파트너            | 먼저 말 걸고 할 일에 반응할 상대 한 명                                                                |
| 캐릭터 디스플레이 | 상대마다 세울 그림. 지금 얘기하는 상대 그림만 선다. 그림 숨기기, 그림이 없어도 자리 비워두기도 여기서 |
| 호감도 표시       | 수다 화면 머리말에 호감도를 띄울지, 칸마다 쓸 이모지                                                  |
| 비밀 쪽지         | 먼저 거는 말을 쪽지로 보낼지, 한 번 눌러 열지 두 번 눌러 열지                                         |
| 말풍선 뜸         | 두 번째 말풍선부터 치는 만큼 쉬었다 올릴지, 얼마나 쉴지 (ms/바이트, 한글 한 글자는 3바이트)           |

> 기본 마도카보다 옆으로 넓은 그림을 고르면 어떻게 세울지 묻는다 — **가로에 맞추기**(마도카 너비에 맞춰 줄임) 또는 **왼쪽으로 넓게**(키는 그대로, 넘치는 만큼 왼쪽으로). 미리보기를 보고 누르면 된다.

**📁 훑을 폴더** — 폴더 이름만 쳐도 열 수 있게 훑어둘 뿌리 폴더. 바꾸면 새로 훑는다. 처음 켤 땐 이 탭부터 뜬다.

## 필요한 것

- Windows 10/11
- JDK 21 이상
- Maven 3.8 이상 (`mvn` 이 PATH 에 있어야 한다)
- (선택) Gemini API 키 — 목표 쪼개기, 수다, 캡쳐 OCR 에 쓴다. 없어도 런처 기능은 돈다

## 설치

```bat
git clone <저장소 주소> Kyubey
cd Kyubey
mvn clean javafx:run
```

처음 켤 때 설치된 앱 목록(`installed.json`)을 한 번 훑어서 만든다. 기록 파일들
(`chat.json`, `history.json` 등)은 없으면 알아서 새로 생긴다.

### 1. Gemini 키 (`.env`)

프로젝트 루트에 `.env` 를 만들고 [Google AI Studio](https://aistudio.google.com/apikey) 에서
받은 키를 적는다. **`WIZ_` 로 시작하는 이름만 읽는다**
키를 여러 개 적으면 번호순으로 돌려 쓰면서, 한도가 찬 키는 건너뛴다.
위젯에서 `keys` 를 치면 창에서 바로 넣고 뺄 수 있다 (저장하면 껐다 켜지 않아도 먹는다).

```env
WIZ_1=발급받은키
WIZ_2=두번째키

# 선택: 모델 바꾸기 (재빌드 없이 여기만 고치면 된다)
# GEMINI_MODEL=gemini-3.8-flash
# GEMINI_FAST_MODEL=
```

`.env` 는 `.gitignore` 에 들어 있다. 저장소에 올리지 말 것.

### 2. 콘솔 창 없이 켜기

`run.vbs` 를 더블클릭하면 콘솔 창을 숨긴 채로 `run.bat` 을 돌린다. 윈도우와 같이 켜려면
`Win+R` → `shell:startup` 폴더에 `run.vbs` 바로가기를 넣는다.

> `run.bat` 은 자기가 있는 폴더로 옮겨가서 돌리니 어디에 받아도 된다.

## 내 것으로 채우기

등록한 것들은 `src/main/resources/json/` 에 있다. `new` / `edit` 로 위젯 안에서 고치면 되고,
파일을 직접 고쳐도 된다.

| 파일                        | 담는 것                                                                                                  | 저장소    |
| --------------------------- | -------------------------------------------------------------------------------------------------------- | --------- |
| `apps.json`                 | 이름 → 실행 파일/바로가기 경로                                                                           | 안 올라감 |
| `sites.json`                | 이름 → 검색도 되는 사이트 주소                                                                           | 올라감    |
| `bookmarks.json`            | 이름 → 열기만 하는 사이트 주소 (`search` 없음)                                                           | 안 올라감 |
| `aliases.json`              | 딴 이름 → 등록해둔 것 (`yt` → 유튜브)                                                                    | 안 올라감 |
| `cmds.json`                 | 이름 → 폴더에서 돌릴 명령                                                                                | 안 올라감 |
| `editors.json`              | 쓰는 에디터                                                                                              | 올라감    |
| `installed.json`            | 이 컴퓨터에 깔린 앱 (`scan` 으로 새로 훑는다)                                                            | 안 올라감 |
| `dirs.json`                 | 폴더 이름 → 경로                                                                                         | 안 올라감 |
| `settings.json`             | `설정` 창에서 고른 것                                                                                    | 안 올라감 |
| `history.json`, `top.json`  | 검색 기록, 많이 쓴 것                                                                                    | 안 올라감 |
| `partners/{id}/`            | 상대마다 하나씩 (`pink` 마도카 · `yellow` 마미 · `sky` 사야카 · `gray` 호무라) — 아래 파일들이 들어 있다 | 안 올라감 |
| ㄴ `prompt.json`            | 성격문, 먼저 말 걸기 · 할 일 재촉/칭찬 안내문                                                            |           |
| ㄴ `chat.json`, `memo.json` | 나눈 대화, 추려둔 기억                                                                                   |           |
| ㄴ `presence.json`          | 언제 들렀고 언제 읽었는지, 먼저 말 건 때                                                                 |           |
| ㄴ `affection.json`         | 호감도와 오르내린 사유                                                                                   |           |
| ㄴ `chats_old/`             | `채팅 삭제` 로 보관한 지난 대화 (+ 그때 호감도)                                                          |           |
| `goals.json`                | 목표 쪼개기 맵들과 칸 메모, 마도카랑 주고받은 말                                                         | 안 올라감 |
| `notepad.json`              | 메모장 메모들                                                                                            | 안 올라감 |
| `todo/`                     | 할 일 카테고리(`categories.json`)와 날마다 쌓이는 할 일 (`2026-10-06.json` …)                            | 안 올라감 |

`search` 주소를 적어둔 사이트만 검색이 된다 (`new` / `edit` 로 저장하면 `search` 가 없는 사이트는
알아서 `bookmarks.json` 으로 간다). 검색어는 주소 끝에 붙고,
주소에 `%s` 가 있으면 그 자리에 들어간다 (`https://namu.wiki/w/%s`). 지금 되는 것:

`유튜브`, `나무위키`, `구글`, `네이버`, `깃허브`, `쿼라`.

`yt`, `namu` 같은 짧은 이름은 `aliases.json` 에 적는 거라 처음엔 비어 있다. `new` 로 딴 이름을 붙이면 된다.
`apps.json`·`cmds.json`·`aliases.json` 은 쓰는 사람마다 달라서 저장소에 올리지 않는다. 없으면 빈 채로 시작한다.
"안 올라감" 인 파일들은 빌드할 때 jar 에도 안 들어간다.

위젯은 이 파일들을 **실행 위치 기준 상대 경로**로 읽고 쓴다. 그래서 항상 프로젝트 루트에서
`mvn javafx:run` 으로 띄운다 (`run.bat` 이 그렇게 한다).

## 알아둘 것

- **파일 주고받기**는 창이 떠 있는 동안만 같은 네트워크에 임시 웹서버를 연다. 주소에 매번 새로
  뽑은 토큰이 붙어서, 토큰이 안 맞으면 404 다. 창을 닫으면 서버도 내려간다.
  Windows 방화벽이 처음에 Java 를 허용할지 물으면 "개인 네트워크" 만 허용하면 된다.
- **구글 렌즈 검색**은 공식 API 가 아니라 브라우저로 폼을 넘기는 방식이라 언젠가 막힐 수 있다.
  막히면 그림은 이미 클립보드에 있으니 렌즈 페이지에서 `Ctrl+V` 하면 된다.
- **캡쳐**는 위젯 창을 숨기지 않는다. 위젯이 안 찍히게 하려면 `Esc` 로 내리고 부른다.
- **윈도우 알림**을 띄우려고 트레이에 위젯 아이콘이 하나 선다. 알림 이름이 "OpenJDK Platform Binary" 대신
  Kyubey 로 뜨게 `HKCU\Software\Classes\AppUserModelId` 에 이름과 아이콘을 적어둔다 (관리자 권한 필요 없음).
